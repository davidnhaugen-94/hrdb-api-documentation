Welcome to the Human Resources Database (HRDb) developer reference. This unified API platform provides companies with a complete human resources database that can be incorporated with existing company internal software.

I created the GoRest HRDb Developer Reference Manual as a self-directed API documentation project, focusing on write-enabled REST APIs and the full CRUD lifecycle.

## Base URL

`https://gorest.co.in`
